# Живая печь — 3D и AR-экспозиция Музея Печи

Независимое веб-приложение: семь разделов, шесть 3D-сцен, исторические референсы, учебные схемы, NFC-ссылки и QR-коды. Работа приложения не требует ChatGPT.

Архив `museum-ar.zip.part-*` разбит на части для загрузки через браузер. GitHub Actions проверяет контрольные суммы, собирает ZIP, извлекает `site/` и публикует его в GitHub Pages. Внутри ZIP также находится редактируемый HTML/CSS/JavaScript и инструкция. Все нужные для 3D модели и библиотеки хранятся локально.

Для обновления замените все части архива и `archive.sha256` одной версией. Не смешивайте части разных сборок. После коммита запускается публикация. Историческая точность пользовательских AI-моделей не подтверждена; источники описаны отдельно в приложении.

AR зависит от телефона и системных служб. Проверка без VPN в музейной сети необходима перед запуском для посетителей.
